# Student Registration System

## About
A simple C# project for practising student registration and Git version control.

## Technologies Used
- C#
- .NET
- Git
- GitHub

## Project Structure
- `StudentRegisterationSystem/` — Contains the Visual Studio solution and C# project files.
- `README.md` — Project documentation.
- `.gitignore` — Specifies files Git should ignore.

## Purpose
This project is used to learn Git commands, commits, GitHub repositories, and collaboration workflows.

## Planned Feature: Student Search

The application will support searching for students by their name.
